# AutoSync MVP UI 

## 1. Індекс Здоров'я (Health Score)
Замість складної таблиці користувач одразу бачить кругову діаграму здоров'я авто (яка анімується при завантаженні). Колір змінюється залежно від статусу (зелений, оранжевий, червоний).

## 2. Смарт-Нагадування
На головному екрані виведено картки нагадувань. Важливі нагадування підсвічуються червоним акцентом з кнопкою "Записатись", щоб стимулювати швидке вирішення проблеми.

## 3. Історія (Верифікований цифровий слід)
У вкладці "Історія" реалізовано гарний таймлайн подій, який виглядає як стрічка соціальної мережі — це саме те, що створює додану вартість вашому продукту при продажі авто. Кнопка "Поділитись для продажу" одразу доступна зверху.

## 4. Швидке додавання
Використано зручну "плаваючу" кнопку (Floating Action Button), яка відкриває модальне вікно знизу екрану — це стандартний і найзручніший патерн для сучасних мобільних додатків.

## Оновлення v1.1 (Стратегічні фічі)

### 1. Інтеграції з Реєстрами
Додано кнопки для синхронізації даних із зовнішніми джерелами:

* Дані МВС: Завантаження історії попередніх реєстрацій (кількість власників, пробіг).
* Звіт CarVertical: Інтеграція для відображення ДТП та аукціонної історії для пригнаних авто. Це дозволяє наповнити історію авто ще до того, як користувач почне додавати власні записи, створюючи миттєву цінність (Wow-ефект).

### 2. Рівні Довіри (Trust Tiers)
Кожна подія в історії тепер має спеціальний бейдж (іконку), який візуально вказує на джерело даних. Це підвищує цінність історії при продажі автомобіля:

* 🟢 Верифіковано в AutoSync: Запис створено в реальному часі через додаток (найвищий рівень довіри).
* 🟣 Оцифровано через ШІ: Дані витягнуті автоматично з фотографії паперового чеку або акту.
* 🔵 Імпортовано з баз (МВС): Офіційні дані з державних реєстрів.
* ⚪️ Додано вручну: Юзер самостійно вписав дані (нижчий рівень довіри, якщо немає фото чеку).

### 3. ШІ-Оцифрування (AI OCR)
В модальному вікні "Новий запис" з'явилася помітна фіолетова кнопка "Оцифрувати документ через ШІ". Вона дозволяє користувачам масово фотографувати старі сервісні книжки та чеки з "бардачка", а ШІ автоматично розпізнає їх і створить відповідні записи у таймлайні. Це вирішує проблему ліні юзера при перенесенні паперової історії в цифровий вигляд.

### 4. Режим "Для Продажу" (Shared View)
Реалізовано окремий екран, який імітує те, що бачить покупець авто, коли переходить за посиланням, яким поділився власник.

Екран містить плашку "Перевірено AutoSync".
Виведено загальну статистику: кількість власників, кількість записів ТО, ДТП.
Доступна кнопка "Завантажити PDF звіт".
Елементи керування (нижнє меню та кнопка додавання) автоматично ховаються, щоб покупець не міг редагувати дані.

## Оновлення v1.2 (Інтеграція Сервісів)

У додатку з'явилася нова повноцінна вкладка "Сервіси". Її головна мета — дати користувачу інструмент для швидкого пошуку СТО, мийок та шиномонтажів навколо нього (концептуальна інтеграція з Google Maps API).

### Особливості вкладки Сервіси:

- 🔍 Розумний пошук та фільтри: Зверху знаходяться чіпи (Всі, СТО, Шиномонтаж, Мийка, Детейлінг), які працюють в реальному часі і фільтрують картки нижче.
- ⭐ Рейтингова система Google: Картки сервісів одразу показують рейтинг та кількість відгуків (наприклад, 4.8 (120)).
- 📍 Дистанція та Статус: Відображається точна відстань до сервісу та його поточний робочий статус (Відчинено до 20:00 або Зачинено (до 09:00)).
- ⚡️ Швидкі дії: Прямо з картки юзер може зателефонувати на СТО або натиснути "Прокласти маршрут", що одразу відкриє навігатор на телефоні.

Цей розділ суттєво підвищує Retention (повернення користувачів), оскільки юзери заходитимуть в AutoSync не тільки раз на півроку для запису в історію, але й щотижня, щоб знайти найближчу мийку з хорошим рейтингом.

## Оновлення v1.3 (Персоналізація та Проактивність)

Проведено роботу над глибокою кастомізацією інтерфейсу, перетворивши стандартний шаблон на унікальне "космічне" рішення (Dark Vision). Крім естетичних змін, додано важливу логіку проактивних сповіщень.

### 1. Візуальний Редизайн (Dark Vision)
Додаток отримав преміальне оформлення з глибоким темним фоном, неоновими акцентами та футуристичною типографікою.

### 2. Проактивні Сповіщення (Push Notifications)
 Реалізовано систему, яка нагадує користувачеві про заплановані події (ТО, страховка). Система використовує локальні сповіщення (Chrome Notifications), щоб показати повідомлення навіть тоді, коли вкладка додатка неактивна.

Це значно підвищує цінність сервісу, оскільки він тепер постійно знаходиться "на радарі" користувача, а не лише тоді, коли заходиш у додаток.

### 3. Автоматичне Сортування (Sort by Due Date)
На вкладці "Нагадування" додано динамічне сортування. Записи автоматично переміщуються у верхню частину списку, якщо дата їхнього виконання наближається (особливо актуально для червоних карток), що дозволяє користувачеві миттєво бачити, які завдання потребують уваги в першу чергу.

## Оновлення v1.4 (Профайл та Авторизація)
У цій ітерації ми додали найважливіші елементи для побудови довіри та безпеки в екосистемі AutoSync.

### 1. Авторизація через Дію (Login View)
Створено стартовий екран входу з футуристичним логотипом та кнопками авторизації.
Кнопка "Увійти через Дія" слугує потужним візуальним якорем для українського ринку. Вона пояснює користувачу, звідки додаток отримує надійні дані про авто та історію (інтеграція з реєстрами МВС).

### 2. Вкладка "Профіль" (Profile View)
Верифікація: Відображення аватару та статусу "Верифіковано Дія", що додає соціального та безпекового капіталу користувачеві.
Гейміфікація та Статистика: Еко-рейтинг (98%) та сумарні витрати на обслуговування авто за рік, щоб користувач міг аналізувати свої фінанси.
Мій Гараж: Секція, де користувач може побачити своє поточне авто (напр. Volkswagen Golf VII) та має змогу зручно "Додати авто" до свого віртуального гаража.
Налаштування: Зручні перемикачі (toggles) для Push-сповіщень та синхронізації з реєстрами МВС.

## Оновлення v1.5 (AI Сканер Авто)

Функціонал перевірки інших автомобілів додано як окрему ключову фічу, що перетворює додаток з простої історії авто на потужний інструмент-агрегатор (аналог CarVertical).

### 1. Зміни в навігації
Вкладку "Профіль" у нижньому меню замінено на "Сканер", що звільнило найзручніше місце для найважливішої фічі. (Профіль тепер доступний через аватарку користувача в шапці додатку).

### 2. Екран "Сканер" (AI Scanner View)
Реалізовано поле для вводу VIN-коду або Держ. номера.
При натисканні на "Аналізувати" відбувається анімована симуляція "Збору даних з реєстрів МВС та СТО".
Після перевірки виводиться AI Report (демонстраційний):
Базова інформація (Модель, Рік, Тип двигуна).
Дані про пробіг та історію ДТП.
Резюме ШІ з оцінкою (напр., 85/100) та висновками щодо доцільності покупки.
